### Phase 3 – Privilege Escalation via CVE-2023-22809

**CVE-2023-22809** allows a user with `sudoedit` permissions to write arbitrary files as root by injecting commands via the `--` argument when the `sudoers` rule uses a wildcard like `(ALL) NOPASSWD: /usr/bin/sudoedit /etc/*`. Many Ubuntu AMIs ship with such misconfigurations.

**Exploit Steps (tool calls after shell access):**

1. On compromised host, check sudoless privileges:  
   `kali_run` → `sudo -l`

2. Identify a writable directory for injection. The attacker can abuse `sudoedit` to create a malicious file in `/etc/profile.d/` or overwrite `/etc/passwd`.

3. Execute payload via MCP `kali_run`:
   ```bash
   sudoedit -s /etc/passwd <<< $'pwned:x:0:0::/root:/bin/bash\n'
   ```
   (In practice, leveraged via `--` in `EDITOR` variable; we'll use a specific Python script to reliably trigger the vulnerability.)

4. Use `mcp__kali-tools__kali_run` to deliver the exploit code (e.g., off‑the‑shelf from Exploit‑DB) and gain root shell. Validate with `id`.
